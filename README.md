# La Granada del 27 · Un siglo después

Edición digital en formato **flipbook** del poemario **La Granada del 27 · Un siglo después**.

## Publicación

Este repositorio está preparado para publicarse directamente mediante **GitHub Pages** desde la rama `main` y la raíz `/`.

La aplicación es completamente estática: no necesita servidor, base de datos ni proceso de compilación.

## Estructura

```text
.
├── .nojekyll
├── index.html
├── manifest.webmanifest
├── README.md
└── pages/
    ├── page-01.webp
    ├── page-02.webp
    ├── ...
    └── page-38.webp
```

## Lectura

El visor permite:

- lectura a página simple y doble página;
- navegación mediante botones, teclado y zonas laterales;
- gesto de deslizamiento en dispositivos móviles;
- vista de miniaturas;
- pantalla completa;
- funcionamiento local sin conexión una vez descargados los archivos.

## Despliegue en GitHub Pages

En **Settings → Pages**, seleccionar:

- **Branch:** `main`
- **Folder:** `/ (root)`

La página principal es `index.html`.
