# Espejo 06 ↔ 22

## MANUEL ÁNGELES ↔ LOS OTROS

### Mecanismo

**encuadrar ↔ desbordar el encuadre**

No comparten número de versos, métrica ni estructura matricial. La relación está en el borde.

### MANUEL ÁNGELES

El poema parte de una composición centrada. Cada acción desplaza el límite: una línea se borra, una sombra no prevista entra, una mancha cruza donde terminaba el dibujo y finalmente el gesto decisivo no corrige el centro, sino que ensancha el borde.

### LOS OTROS

El poema trabaja con una fotografía que cambia cada vez que se modifica el recorte. Al ampliar aparecen cuerpos parciales, manos, una escoba, un niño, una mujer con bandeja. Cada intento de incluir a alguien vuelve a dejar a otro fuera. La solución no es encontrar el recorte perfecto, sino admitir el margen.

### Correspondencias

- línea borrada ↔ recorte desplazado
- sombra inesperada ↔ medio cuerpo reaparecido
- mancha que cruza el límite ↔ brazo/escoba que entran por el margen
- ensanchar el borde ↔ dejar de cortar la copia
- centro insuficiente ↔ marco insuficiente

### Regla propia de este espejo

**No hay un encuadre neutral. Si el borde excluye lo que importa, se cambia el borde.**

Este mecanismo no debe repetirse obligatoriamente en otros dípticos.
